zhao_geom_arenabin -- WHICH ARRAYS QUARTUS 17.0.2 TURNED INTO MEMORY
====================================================================
Distilled from the Analysis & Synthesis RAM Summary of each map_only row, on
the shipping part 5CSEBA6U23I7. The full *.map.rpt is 1.2 MB and gitignored by
size; this is the twelve lines that carry the finding.

THE FINDING: only the five MODULE-SCOPE directory arrays infer. The staging
array -- 14 banks of 576 x 18 = 145,152 bits, declared INSIDE A GENERATE --
does not appear in any row's RAM Summary, in any variant, and goes to
flip-flops. That is the whole of the difference between the block's declared
177,984 bits of on-chip state and its measured 33,408 block memory bits.
