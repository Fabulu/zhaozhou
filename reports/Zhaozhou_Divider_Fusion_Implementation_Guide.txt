ZHAOZHOU: PROJECTOR DIVIDER COMPARE/SUBTRACT FUSION
DSF-01 -- bounded implementation, verification, measurement and abort guide
Prepared 17 September 2026

PURPOSE
-------
Find out whether a small, bit-exact rewrite can reduce ALMs in the shared
projector, without sacrificing clock margin, throughput, gamefeel, FIELD,
rendering quality, or any existing numerical behavior.

This is an EXPERIMENT, not an instruction to obtain a predetermined saving.
The acceptable outcomes include "Quartus already does this; stop" and "the
rewrite costs timing; revert". Do not turn a failed small experiment into a
new projector rearchitecture campaign.

The sole proposed production change is inside the repeated restoring-divider
step in:
    fpga/rtl/common/zhao_project_core.sv

Replace the separately expressed unsigned comparison and subtraction with a
33-bit unsigned subtraction whose high bit supplies the borrow decision.
Keep every existing register, pipeline stage, handshake, enable, reset,
quotient convention and output packet.

Planning hypothesis: about 1,000 ALMs per physically instantiated shared
projector, CONDITIONAL on duplicate arithmetic surviving baseline synthesis.
An illustrative successful range was 500-1,500 ALMs. Zero or negative savings
remain entirely possible. This is not a measured range, confidence interval,
or guaranteed saving. Do not enter it in the resource budget.

READ THIS FIRST
---------------
1. Work in isolated checkouts. Do not edit the active Packet-H/G8C checkout.
2. Prove the exact step rewrite and fire its failure controls.
3. Compare matched Quartus maps before spending any full fit.
4. Run fresh functional and cycle-level regressions.
5. Fit a matched physical-pin seed-2 pair only if there is a reason to proceed.
6. Confirm a promising result with a matched physical-pin seed-4 pair.
7. Adopt only under the predeclared acceptance policy; otherwise stop and
   preserve the evidence. A clean negative result finishes this experiment.

Do not broaden this task to shared reciprocals, reduced precision, CPU offload,
new dividers, DSP packing, FIELD changes, Packet H, G8C, or V20 cleanup.
Those are independent projects.

2. EXACT CONTRACT AND WHY THE ARITHMETIC IS EQUIVALENT
===============================================================================

The current step reads:
    dv: 63-bit unsigned state
    d : 31-bit unsigned divisor

It constructs:
    t    = {dv[61:31], dv[30]}       // 32 bits
    tail = dv[29:0]                 // 30 bits

The old next state is:
    if t >= zero_extend_32(d):
        next = {t - zero_extend_32(d), tail, 1'b1}
    else:
        next = {t,                     tail, 1'b0}

Both selected results are exactly 63 bits. dv[62] is not used in constructing
this step's t; preserve that fact rather than changing the recurrence.

Define a 33-bit UNSIGNED subtraction:
    difference = zero_extend_33(t) - zero_extend_33(d)
    take_sub   = NOT difference[32]

When t >= d:
    0 <= t-d <= 2^32-1.
The 33rd bit is therefore zero, take_sub is one, and difference[31:0] is the
same 32-bit subtraction result as the old branch.

When t < d:
    -(2^31-1) <= t-d <= -1.
The unsigned 33-bit wrapped value has bit 32 set. take_sub is zero and the
selected remainder is t, exactly as before. The low wrapped subtraction bits
are discarded in this case.

Equality is important: t=d produces difference=0, take_sub=1, remainder=0 and
quotient bit=1. A strict greater-than condition would be wrong.

The argument does NOT assume d is nonzero, rem<d, a legal matrix, a visible
vertex, or an in-range projected result. Even d=0 is covered: subtraction by
zero produces take_sub=1, which matches the old unsigned t>=0 branch. The
full-domain proof is deliberately stronger than the usual runtime invariant.

WHY BIT 31 IS WRONG
-------------------
Bit 31 can be one for a perfectly nonnegative 32-bit difference. It is not the
borrow bit. Example: t=0x80000000, d=0. The subtraction is legal and must be
taken, even though difference[31] is one. Use difference[32].

WHY ZERO EXTENSION MUST BE EXPLICIT
----------------------------------
The operands are not signed. Use exactly:
    {1'b0, t}                 // 33 bits
    {2'b0, dstep_d[gs]}       // 33 bits

Do not substitute $signed casts, unsized arithmetic constants, or a 32-bit
subtraction whose high bit is inspected after it has already wrapped.

SEQUENTIAL CONSEQUENCE
----------------------
The local next-state functions are equal for all binary input states. If every
register update, reset, enable and inter-stage connection stays unchanged,
induction from reset gives the same registered divider state on every clock.
Stalls preserve the same state; resets create the same state; configuration
and data traffic see the same state transitions.

This justifies BIT- AND CYCLE-EXACT behavior, not just visual equivalence.
No error tolerance, alternate rounding, new timing calendar or golden update
is needed or permitted by this experiment.

The formal model is two-state. It does not promise identical X/Z propagation
for uninitialized four-state simulation inputs. Keep reset discipline and
valid-data checks intact; never mask a meaningful simulation failure with X
assignments or case equality.

PHYSICAL CONSEQUENCE IS NOT PROVEN
---------------------------------
The rewrite offers Quartus one explicitly shared result/decision. It does not
force a particular ALM topology. A separate comparator can also have a faster
implementation than the full subtraction carry chain, so removing it could
hurt the subtract-to-mux timing path. Only mapping and fitting settle that.

The earlier ALM estimate used the rough scale of a 32-bit carry structure and
93 source repetitions. Cyclone V arithmetic ALMs contain two dedicated full
adders, but a comparator is not automatically one full adder per bit, register
packing is not linear, and some repeated stages may simplify. [W1]

3. THE PRODUCTION PATCH
===============================================================================

Edit only the combinational slice inside g_div_lane. Keep the generate labels,
register declaration and sequential block recognizable. Do not introduce a
runtime option or retain two selectable production divider implementations.

CURRENT BODY
------------

        logic [31:0] t;
        logic [62:0] nxt;
        logic [62:0] r_dv;
        always_comb begin
          t   = {dstep_dv[gs][gl][61:31], dstep_dv[gs][gl][30]};
          nxt = (t >= {1'b0, dstep_d[gs]}) ?
              {t - {1'b0, dstep_d[gs]}, dstep_dv[gs][gl][29:0], 1'b1} :
              {t, dstep_dv[gs][gl][29:0], 1'b0};
        end

REPLACEMENT BODY
----------------

        logic [31:0] t;
        logic [32:0] difference;
        logic take_sub;
        logic [62:0] nxt;
        logic [62:0] r_dv;
        always_comb begin
          t = {dstep_dv[gs][gl][61:31], dstep_dv[gs][gl][30]};
          difference = {1'b0, t} - {2'b0, dstep_d[gs]};
          take_sub = ~difference[32];
          nxt = {(take_sub ? difference[31:0] : t),
                 dstep_dv[gs][gl][29:0], take_sub};
        end

The existing always_ff block immediately after this body stays UNCHANGED:

        always_ff @(posedge clk or negedge rst_n) begin
          if (!rst_n) r_dv <= '0;
          else if (en_i) r_dv <= nxt;
        end
        assign dstep_dv[gs+1][gl] = r_dv;

Do not move the operation across that register. Do not change DIV_STEPS,
divisor width, r_dv width, metadata delay lines, or anything in the row-products,
viewport, saturation, quotient assembly, near-plane, or configuration sections.

The new logic declarations are combinational wires/signals, not state.
Expected source-level cost changes:
    + one named 33-bit difference signal;
    + one named decision signal;
    - separately expressed >= operation in this particular recurrence;
    + no registers, stages, memories, DSP operations or external ports.

Allowed supporting changes, only when necessary:
    - refresh the existing projector MUTANT COPY to this body while retaining
      its original and only MATW-refusal mutation;
    - regenerate current source-hash manifests through their existing generator;
    - add test-only proof/regression files and their explicit registrations;
    - add the experiment report and named evidence rows.

Changing a current provenance hash after a real source edit is not falsifying a
receipt. Editing a historical fit row so it appears to certify the new source
IS falsification. Preserve old measurements as measurements of old specimens.

7. ABORT, DIAGNOSIS AND ROLLBACK GUIDE

7.1 Stop classes
----------------
ALREADY_DONE
    The live baseline is already fused or the candidate is unchanged.
    Action: document and stop. Do not create synthetic work.

BLOCKED_BASELINE / BLOCKED_TOOL / BLOCKED_RESOURCE
    Missing tools, unavailable fit queue, invalid baseline, unrun required test,
    timeout or a genuinely missing report prevents a verdict.
    Action: preserve all logs and state exactly what is missing. This says
    nothing about whether the optimization is good or bad.

FAIL_FUNCTIONAL
    Source-derived proof, cycle behavior, oracle outputs, or required
    fault-control behavior differs.
    Action: preserve counterexample; no mapping/fit until corrected. One small
    clerical repair is allowed; algorithmic redesign is not.

NO_STRUCTURAL_GAIN
    A proper map comparison shows the baseline already uses the same logic.
    Action: stop before physical fits. Remove/abandon the production patch.

NO_PHYSICAL_GAIN
    Proper matched physical measurements show no placed ALM saving.
    Action: preserve map/fit results and retain the incumbent implementation.

SMALL_WIN_NOT_AUTO_ADOPTED
    It is exact and saves area, but misses the preset 250-ALM-per-seed threshold.
    Action: report the real saving; stop. Further adoption is an explicit owner
    choice, not a pretext to reinterpret the original ~1,000 estimate.

TIMING_OR_RESOURCE_REGRESSION
    It is exact but spends excessive WNS, fails 100 MHz/hold, or adds DSP/RAM.
    Action: reject under the preset policy. Do not "repair" it by extra stages,
    relaxed clocks, new false paths, width changes, or borrowing DSPs.

MEASUREMENT_INVALID
    Wrong cone/parameters, stale binary/row, mismatched pin mode, source edited
    mid-fit, missing constraints, dead datapath or invalid report attribution.
    Action: discard the COMPARISON, not the logs. Recreate the affected pair only
    if the mistake is small and the fit budget/owner allows it. No savings claim.

PASS_LOCAL
    Both source/cycle tests and both matched physical pairs pass policy.
    Action: prepare controlled adoption and the evidence-qualified report.

7.2 First diagnosis by symptom
-----------------------------
Fails at t=d:
    Check borrow polarity and equality handling. take_sub must be one.

Fails at t>=0x80000000:
    Check for bit-31-as-sign mistakes or signed arithmetic. Use bit 32 of a
    zero-extended 33-bit subtraction, not bit 31 of a 32-bit value.

Fails only when subtraction is refused:
    Ensure the remainder selects the original t, not wrapped low subtraction
    bits. Quotient bit must also be zero.

Remainder right, quotient wrong:
    Compare the ENTIRE 63-bit next state. Tail/quotient packing is part of the
    operation. A checker looking only at the remainder is incomplete.

Pure proof passes, end-to-end test fails:
    Suspect patch outside the proved slice, stale/incorrect build, the wrong
    source selected, copied mutant drift, or a driver error. Preserve the first
    differing cycle/packet; do not change rounding to match it.

Map summaries identical:
    Determine whether they report combinational resources. Register/DSP/RAM
    equality is expected and cannot by itself reject the hypothesis.

Map smaller but fitter ALMs unchanged:
    Packing and placement absorbed the difference. The actual objective did
    not improve at this boundary. Report that, not an imaginary ALM saving.

ALMs improve but timing worsens:
    The borrow decision may now lie on the subtraction carry-to-mux path or
    route/fanout may be worse. That trade is plausible. Reject it under this
    experiment's no-material-timing-loss policy; do not start another campaign.

Mutant "fails" before the solver/test executes:
    It was not detected. Repair the test instrument or leave the gate blocked.
    Build errors, crashes, missing modules and timeouts are not counterexamples.

7.3 Safe rollback BEFORE production adoption
--------------------------------------------
The safest rollback is no change at all to the active branch: leave B unmerged
and mark the experiment closed. Preserve the candidate SHA, source patch and
results on its isolated branch/evidence archive.

If B is already committed, capture its implementation SHA before any cleanup:
    git -C <B> show --stat <IMPLEMENTATION_SHA>
    git -C <B> diff <BASE> <IMPLEMENTATION_SHA> -- <explicit owned paths>

A single candidate implementation commit should contain the core change and
necessary mutant/manifest coherence. If a rollback commit is desired IN B:
    git -C <B> status --porcelain
    git -C <B> revert --no-edit <IMPLEMENTATION_SHA>

Do not execute revert on a dirty tree. Resolve report/provenance conflicts
manually if necessary; do not use a blanket conflict strategy. If implementation
spans several dependent commits, identify them explicitly and revert newest to
oldest, preserving unrelated work and evidence.

If the candidate is still uncommitted, archive its diff and stop using the
isolated worktree. There is no need to erase it. Restore individual owned files
only after verifying they contain no other agent's work; never use a whole-tree
reset or clean to make the status look tidy.

Prohibited cleanup shortcuts:
    git reset --hard on a shared/unknown checkout;
    git clean -fdx;
    force-pushing a branch to erase the attempt;
    killing all Quartus/Verilator processes by name;
    deleting the only completed map/fit database before evidence extraction;
    overwriting historical receipts with restored numbers.

If the restored core is intended for further use, verify its canonical bytes
match A, regenerate any current source manifests, and rerun the focused proof/
regression checks. Exact restored source may refer to the old valid fit evidence;
do not invent a new physical measurement.

7.4 Rollback AFTER controlled adoption
--------------------------------------
Revert the specific integration commit on the destination branch. Do NOT reset
that branch to BASE: it may contain other people's later work. Keep the current
mutant copy coherent with the restored core, regenerate current manifests, and
rerun the affected regression slice.

If intervening edits touched the recurrence or the same manifests, merge the
rollback deliberately. If old hardware source bytes are no longer restored,
old fit receipts no longer certify this new combination. Record that limitation
and run the appropriate new gate instead of relabeling an old row.

7.5 Boundedness rule
--------------------
This task ends after one genuine source-form hypothesis, one matched map pair,
and at most two matched physical seed pairs. Small clerical/infrastructure
repairs must be logged. A different subtract architecture, explicit vendor
primitive, timing stage, word width, reciprocal scheme, or scheduling change
is a NEW experiment, not "DSF-01 attempt 27".

    5. What happened to setup, hold, DSPs, RAM blocks and memory bits?

#!/usr/bin/env python3
"""Export source-derived divider-step proofs. Never modifies repository files."""
from __future__ import annotations
import argparse
import hashlib
import json
from pathlib import Path
import re
import sys

LANE = '      for (gl = 0; gl < 3; gl = gl + 1) begin : g_div_lane'
REGISTER = '        always_ff @(posedge clk or negedge rst_n) begin'
ORIGINAL = """
        logic [31:0] t;
        logic [62:0] nxt;
        logic [62:0] r_dv;
        always_comb begin
          t   = {dstep_dv[gs][gl][61:31], dstep_dv[gs][gl][30]};
          nxt = (t >= {1'b0, dstep_d[gs]}) ?
              {t - {1'b0, dstep_d[gs]}, dstep_dv[gs][gl][29:0], 1'b1} :
              {t, dstep_dv[gs][gl][29:0], 1'b0};
        end
"""

def squash(s: str) -> str:
    return re.sub(r'\s+', '', s)

def split_lane(text: str) -> tuple[str, str, str]:
    if text.count(LANE) != 1:
        raise ValueError('Expected exactly one known g_div_lane generate body; inspect live source.')
    if not re.search(r'\bDIV_STEPS\s*=\s*31\s*;', text):
        raise ValueError('Expected DIV_STEPS=31; re-scope rather than guessing.')
    start = text.index(LANE) + len(LANE)
    end = text.find(REGISTER, start)
    if end < 0:
        raise ValueError('Register boundary missing; refusing extraction.')
    body = text[start:end]
    if body.count('always_comb') != 1:
        raise ValueError('Expected one combinational block.')
    return text[:start], body, text[end:]

def replace_once(s: str, before: str, after: str) -> str:
    if s.count(before) != 1:
        raise ValueError(f'Expected one mutation anchor: {before!r}')
    return s.replace(before, after, 1)

def module(name: str, body: str) -> str:
    # These are local textual aliases, not changes to the expressions.
    body = body.replace('dstep_dv[gs][gl]', 'dv_i')
    body = body.replace('dstep_d[gs]', 'd_i')
    body = replace_once(body, 'logic [62:0] r_dv;', '')
    if any(x in body for x in ('dstep_', '[gs]', '[gl]', '`', '$', 'always_ff')):
        raise ValueError('Unexpected external dependency/preprocessor content in proof slice.')
    return (f'module {name}(input logic [62:0] dv_i, input logic [30:0] d_i,\n'
            '                   output logic [62:0] nxt_o);\n' + body +
            '\nassign nxt_o = nxt;\nendmodule\n')

def bundle(out: Path, name: str, a: str, b: str) -> None:
    folder = out / name
    folder.mkdir()
    (folder / 'a.sv').write_text(module('step_a', a), encoding='utf-8')
    (folder / 'b.sv').write_text(module('step_b', b), encoding='utf-8')
    (folder / 'miter.sv').write_text('''module divstep_miter(
  input logic [62:0] dv_i,
  input logic [30:0] d_i,
  output logic [62:0] a_o,
  output logic [62:0] b_o,
  output logic eq_o
);
step_a a(.dv_i(dv_i), .d_i(d_i), .nxt_o(a_o));
step_b b(.dv_i(dv_i), .d_i(d_i), .nxt_o(b_o));
assign eq_o = (a_o == b_o);
endmodule
''', encoding='utf-8')
    (folder / 'prove.ys').write_text('''read_verilog -sv a.sv b.sv miter.sv
hierarchy -check -top divstep_miter
proc
flatten
opt
check -assert
sat -verify -prove eq_o 1 -show-inputs -show-outputs -dump_vcd counterexample.vcd
''', encoding='utf-8')

def main() -> int:
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument('--baseline', type=Path, required=True)
    p.add_argument('--candidate', type=Path, required=True)
    p.add_argument('--out', type=Path, required=True)
    a = p.parse_args()
    raw_a = a.baseline.read_bytes()
    raw_b = a.candidate.read_bytes()
    # Normalize line endings for source comparison only; preserve raw digests.
    sa = raw_a.decode('utf-8-sig').replace('\r\n', '\n')
    sb = raw_b.decode('utf-8-sig').replace('\r\n', '\n')
    pre_a, body_a, post_a = split_lane(sa)
    pre_b, body_b, post_b = split_lane(sb)
    if (pre_a, post_a) != (pre_b, post_b):
        raise ValueError('Core changed outside the permitted combinational slice; abort.')
    if squash(body_a) != squash(ORIGINAL):
        raise ValueError('Baseline no longer matches reviewed recurrence; inspect/re-scope.')
    if squash(body_a) == squash(body_b):
        raise ValueError('Candidate is unchanged; refusing a vacuous A/A experiment.')
    mutants = {
        'M1_inverted_borrow': replace_once(body_b, 'take_sub = ~difference[32];',
                                          'take_sub = difference[32];'),
        'M2_wrong_bit31': replace_once(body_b, 'take_sub = ~difference[32];',
                                      'take_sub = ~difference[31];'),
        'M3_unchanged_remainder': replace_once(body_b, 'take_sub ? difference[31:0] : t',
                                              'take_sub ? t : t'),
        'M4_inverted_quotient': replace_once(body_b, 'dstep_dv[gs][gl][29:0], take_sub',
                                            'dstep_dv[gs][gl][29:0], ~take_sub'),
    }
    # Refuse overwrites, including old proof results.
    a.out.mkdir(parents=True, exist_ok=False)
    bundle(a.out, 'A_equals_A', body_a, body_a)
    bundle(a.out, 'healthy', body_a, body_b)
    for name, body in mutants.items():
        bundle(a.out, name, body_a, body)
    meta = {
        'baseline_path': str(a.baseline.resolve()),
        'candidate_path': str(a.candidate.resolve()),
        'baseline_raw_sha256': hashlib.sha256(raw_a).hexdigest(),
        'candidate_raw_sha256': hashlib.sha256(raw_b).hexdigest(),
        'baseline_slice_sha256': hashlib.sha256(body_a.encode()).hexdigest(),
        'candidate_slice_sha256': hashlib.sha256(body_b.encode()).hexdigest(),
        'outside_slice_equal_after_newline_normalization': True,
        'expected': {'A_equals_A': 'PASS', 'healthy': 'PASS', **{k: 'COUNTEREXAMPLE' for k in mutants}},
        'stage': 'export-only',
        'generated_files_sha256': {
            str(f.relative_to(a.out)): hashlib.sha256(f.read_bytes()).hexdigest()
            for f in sorted(a.out.rglob('*')) if f.is_file()
        },
    }
    (a.out / 'manifest.json').write_text(json.dumps(meta, indent=2)+'\n', encoding='utf-8')
    print('Exported source slices and six proof cases. NO PROOF HAS RUN.')
    return 0

if __name__ == '__main__':
    try:
        raise SystemExit(main())
    except (OSError, ValueError, UnicodeError) as exc:
        print(f'ERROR: {exc}', file=sys.stderr)
        raise SystemExit(2)

#!/usr/bin/env python3
"""Run exported Yosys proofs; tool errors are NOT successful mutant kills."""
from __future__ import annotations
import argparse
import hashlib
import json
from pathlib import Path
import subprocess
import sys

PASS_MARK = 'SAT proof finished - no model found: SUCCESS!'
FAIL_MARK = 'SAT proof finished - model found: FAIL!'
EXPECTED = {
    'A_equals_A': 'PASS',
    'healthy': 'PASS',
    'M1_inverted_borrow': 'COUNTEREXAMPLE',
    'M2_wrong_bit31': 'COUNTEREXAMPLE',
    'M3_unchanged_remainder': 'COUNTEREXAMPLE',
    'M4_inverted_quotient': 'COUNTEREXAMPLE',
}

def main() -> int:
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument('--proof-dir', type=Path, required=True)
    p.add_argument('--yosys', default='yosys', help='Executable path, not a shell command.')
    p.add_argument('--timeout', type=int, default=120, help='Per-case limit in seconds.')
    a = p.parse_args()
    if a.timeout <= 0:
        p.error('--timeout must be positive')
    manifest = json.loads((a.proof_dir/'manifest.json').read_text(encoding='utf-8'))
    if manifest.get('expected') != EXPECTED:
        raise ValueError('Proof inventory must contain exactly the six required cases.')
    for side in ('baseline', 'candidate'):
        path = Path(manifest[f'{side}_path'])
        actual = hashlib.sha256(path.read_bytes()).hexdigest()
        if actual != manifest[f'{side}_raw_sha256']:
            raise ValueError(f'{side}: source changed after export; re-export and re-prove.')
    expected_files = {str(Path(case)/name) for case in EXPECTED
                      for name in ('a.sv','b.sv','miter.sv','prove.ys')}
    digests = manifest.get('generated_files_sha256', {})
    if set(digests) != expected_files:
        raise ValueError('Generated proof-file inventory is incomplete or unexpected.')
    for name, expected_hash in digests.items():
        actual = hashlib.sha256((a.proof_dir/name).read_bytes()).hexdigest()
        if actual != expected_hash:
            raise ValueError(f'{name}: exported proof changed; do not certify it.')
    rows = []
    for name, expected in manifest['expected'].items():
        work = a.proof_dir/name
        if any((work/x).exists() for x in ('yosys.log','console.txt','counterexample.vcd')):
            raise ValueError(f'{name}: stale output exists; use a fresh export directory.')
        try:
            r = subprocess.run([a.yosys,'-l','yosys.log','-s','prove.ys'], cwd=work,
                               stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
                               text=True, errors='replace', timeout=a.timeout, check=False)
            (work/'console.txt').write_text(r.stdout, encoding='utf-8')
            logfile = work/'yosys.log'
            log = logfile.read_text(encoding='utf-8',errors='replace') if logfile.exists() else r.stdout
            if expected == 'PASS':
                ok = r.returncode == 0 and PASS_MARK in log and FAIL_MARK not in log
            else:
                # -verify must fail for the actual SAT counterexample, not parsing.
                ok = r.returncode != 0 and FAIL_MARK in log and (work/'counterexample.vcd').is_file()
            row = {'case':name, 'expected':expected, 'exit_code':r.returncode, 'passed':ok}
        except subprocess.TimeoutExpired:
            row = {'case':name, 'expected':expected, 'passed':False, 'error':'TIMEOUT: inconclusive'}
        rows.append(row)
        print(json.dumps(row))
        if not row['passed']:
            break
    ok_all = len(rows) == len(manifest['expected']) and all(x['passed'] for x in rows)
    (a.proof_dir/'results.json').write_text(json.dumps({'all_passed':ok_all,'results':rows},indent=2)+'\n',encoding='utf-8')
    return 0 if ok_all else 1

if __name__ == '__main__':
    try:
        raise SystemExit(main())
    except (OSError, ValueError, KeyError) as exc:
        print(f'ERROR: {exc}', file=sys.stderr)
        raise SystemExit(2)

END FILE: run_divstep_proofs.py

APPENDIX C. INDEPENDENT STANDALONE ARITHMETIC CHECK
===============================================================================

This SMT-LIB file expresses the same two-state recurrence at the bit-vector
level. It was checked by the document author through the installed Z3 library.
On an ordinary Z3 command-line installation:
    z3 -smt2 divstep_formula.smt2
Expected output:
    unsat

This is independent arithmetic evidence. It is NOT a replacement for compiling
the source-derived SystemVerilog miter in Appendices A/B.

BEGIN FILE: divstep_formula.smt2

(set-logic QF_BV)
(declare-fun dv () (_ BitVec 63))
(declare-fun d () (_ BitVec 31))
(define-fun t () (_ BitVec 32) ((_ extract 61 30) dv))
(define-fun tail () (_ BitVec 30) ((_ extract 29 0) dv))
(define-fun d32 () (_ BitVec 32) ((_ zero_extend 1) d))
(define-fun old_take () Bool (bvuge t d32))
(define-fun old_rem () (_ BitVec 32) (ite old_take (bvsub t d32) t))
(define-fun old_next () (_ BitVec 63) (concat old_rem (concat tail (ite old_take #b1 #b0))))
(define-fun diff () (_ BitVec 33) (bvsub ((_ zero_extend 1) t) ((_ zero_extend 2) d)))
(define-fun new_take () Bool (= ((_ extract 32 32) diff) #b0))
(define-fun new_rem () (_ BitVec 32) (ite new_take ((_ extract 31 0) diff) t))
(define-fun new_next () (_ BitVec 63) (concat new_rem (concat tail (ite new_take #b1 #b0))))
(assert (not (= old_next new_next)))
(check-sat)

END FILE: divstep_formula.smt2
