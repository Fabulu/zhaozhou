## Regenerating

```
git log --format='%H|%ad|%s' --date=short --grep='please read' -i
```
then take each commit's added files. Run it as part of any docket sweep; it is
cheap and it is how the three texture briefs were found.

## The standing rules this serves

1. **Owner documents land wherever they land** -- repo root included. Sweep
   there, not only `reports/`.
2. **Scan commit subjects addressed to an agent.** Every file above was announced
   in its commit message; several were never announced anywhere else.
3. **Index a new owner document in the same pass that reads it** (`DOCKET.md`).
4. **A run folder is the wrong home for durable direction** -- every pass creates
   a new one, so anything left there is orphaned by the next.
