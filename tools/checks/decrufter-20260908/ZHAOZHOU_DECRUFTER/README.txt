Start with the architecture TXT. Its opening decision and section 14 specify
the work order. The source index identifies the audited snapshot and the limits
of each class of evidence. No repository code was modified by this package.

independent_checks.py uses only Python 3.10+ standard-library modules.
Run: python independent_checks.py
It writes independent_results.json. The packaged log/results are the author's
actual local execution, but NOT tests of the repository RTL or Quartus.
Accepted/emitted counts differ across reset tests only by explicitly recorded
cancelled records; the models assert that conservation law.

audit_manifest.json contains immutable source references and audit scope.
handoff_state.json contains the final branch refresh observation.
acceptance_receipt_template.json is a blank template for the implementation
agent's real measurements. Null fields are intentionally unmeasured.

This ZIP does not contain an archived repository, compiled bitstream, RTL patch,
or fitted source snapshot. Do not cite its finite Python checks as proof that
an implementation closes timing.
