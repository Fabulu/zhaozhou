## Validation Budget — `V11-LIGHT-BUDGET-1`

Set before diagnostics or rendering. Stop when all three questions are answered.

1. **Structural question:** one source/state-flow audit plus one identical-pose unlit/normals/baseline set and the smallest existing normal/temporal probe needed to decide whether a transform/normal/winding/state defect survives. No catalogue run.
2. **Art question:** one identical native 384×240 baseline-plus-options comparison. Iterate by replacing this small set, not adding campaigns. Permit one short representative deforming clip only if the static comparison cannot establish stability.
3. **Release question:** exact media existence/decodability, one desktop and one narrow comparison-section browser check, exact noindex count, and cache-bypassed production equality for index plus one representative image/video per compared rig.

Escalation requires a concrete unexplained discontinuity, state mismatch, malformed comparison output or website/media failure. No every-frame catalogue review, catalogue rerender or spring validation.
